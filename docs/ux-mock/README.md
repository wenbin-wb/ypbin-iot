# IoT 平台 UX 原型（设计稿，非生产代码）

> 本目录是 `docs/IOT-UX-PROPOSAL.md`（IoT 平台 UX/IA 方案）的**可点击静态原型**。
> 它**不是**生产前端代码，**不参与任何构建**，也不对接任何接口。

## 怎么打开

**方式一（推荐，零依赖）**：直接双击 `index.html`，用浏览器打开即可。
**方式二**：命令行打开

```bash
# Linux
xdg-open docs/ux-mock/index.html
# macOS
open docs/ux-mock/index.html
# Windows (PowerShell)
start docs\ux-mock\index.html
```

**离线保证**：单文件、内联 CSS/JS、**零外部引用**（无 CDN、无外部字体、无外部图片）。
断网也能完整使用。可用下面两条命令自证：

```bash
# 1) 文件里不存在任何 http(s) 链接
grep -c 'http' docs/ux-mock/index.html        # 期望输出 0

# 2) 只有一个 <script> 标签，且没有 <link>/<img>/<iframe>
grep -nE '<(script|link|img|iframe)' docs/ux-mock/index.html
```

## 里面能看到什么

左侧是**新信息架构**（配置 → 设备 → 数据 → 运维 → 系统），每个菜单项带来源标记：

| 标记 | 含义 |
|---|---|
| `复用` | 后端接口与权限码**已经存在**，只差前端页面 |
| `新增` | 需要新增页面（部分还需新增接口） |
| `缺接口` | 后端**完全没有**对应能力，方案里已给出缺口清单 |

### 可点的页面

| 路由 | 页面 | 重点看什么 |
|---|---|---|
| `#/onboarding` | 接入向导（空态三步引导） | 「新建产品 → 定义物模型 → 添加设备并调试」的每步文案与按钮；模板一键生成 |
| `#/templates` | 产品模板中心 | 温湿度传感器 / 三相电表 / 边缘网关模板；点模板会跳到向导第 2 步 |

| `#/products/p1` | **产品详情**（5 个页签） | `物模型` 页签 = 服务 → 属性/命令/事件三层编辑器；`点位模板` 是新概念；`版本` 页签讲缺 diff |
| `#/devices` | 设备台账 | 新增「所属产品 / 分组 / 最新值」列，以及按产品/分组/状态筛选 |
| `#/devices/d1` | **设备详情**（7 个页签） | 概览 / 属性与点位 / 历史曲线 / 事件与断档 / 在线调试 / 设备影子 / 日志 —— 每个区块都标了数据来源 |
| `#/groups` | 设备分组 | 成员管理（后端接口已有、前端没有）+「按分组声明维护」 |

### 每页顶部的「设计标注」

黄色虚线框是**给评审用的**，它回答三件事：

- **进入**：用户从哪进入这个页面
- **点**：这页上要点哪个按钮
- **下一步**：点完之后会发生什么（去哪、看到什么）

红色/绿色框是**缺口与复用提示**：绿色说明「这些接口已经有了」，红色说明「这里后端没有，需要新增什么」。

## 数据说明（重要）

页面里的数据**全部是前端硬编码的假数据**（`index.html` 顶部的 `DB` 常量），
不发起任何网络请求。假数据是**按仓库现状设计的**，包含刻意的细节：

- 设备 `demo-dev-offline` 有一条**进行中**断档 → 用来演示「健康总览」的红色计数与断档明细
- 设备 `demo-dev-never` **从未上报** → 演示「零数据 ≠ 断档」（可用率 100%）
- 设备 `demo-dev-disabled` 是 **已停用**（`status=0`）
- `demo-dev-ungrouped` **不在任何分组里**
- 设备影子页里 **reported 区故意是空的** —— 这不是画错，而是如实反映后端
  `setReported(...)` **只出现在单元测试中**、生产代码从不写 reported 的真实情况

## 与真实代码的边界

- 真实前端实现落在 **`ypbin-iot-ui`**（vben5 + antd，`apps/web-antd/src/views/iot/**`）。
- 本原型只表达**信息架构与交互意图**；组件外观、间距、动效**不保证**与最终实现一致。
- 原型里出现的接口路径、权限码、字段名，均来自对 `ypbin-iot` 后端与 `ypbin-iot-ui` 前端的**实际检索**，
  并在 `docs/IOT-UX-PROPOSAL.md` 的「增量改造清单」一节逐条标注了「复用 / 需新增」。

## 浏览器要求

只需支持 ES2018+ 的现代浏览器（Chrome / Edge / Firefox / Safari 近三年版本）。
原型使用 `location.hash` 做路由，因此**刷新页面会停在当前页**，也可以用浏览器前进/后退。
